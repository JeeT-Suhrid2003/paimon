# Paimon Chat

A modular Paimon companion application using Gemini AI, Tkinter GUI, and TTS audio playback.

---

## 🌟 Demo & Showcase (Perfect for X / Twitter!)

We have built an **automated demo recording suite** that runs a complete simulation of the Paimon Companion in action! It launches the floating desktop Tkinter GUI, walks through a lively conversational script, captures screenshots, records an **MP4 video**, and compiles an **animated GIF** of her expression shifts—all while saving high-quality WAV files of her adorable voice!

### 🎥 Generated Demo Assets

All generated assets are saved in the `demo_assets/` folder:
- **`paimon_demo.gif`**: A lightweight, highly optimized animated GIF showcasing Paimon's mood swings (HAPPY ➡️ THINKING ➡️ SAD ➡️ HAPPY).
- **`paimon_demo.mp4`**: A high-resolution desktop screen recording of her companion window, ideal for posting directly to X!
- **`paimon_welcome.wav`**, **`paimon_thinking.wav`**, **`paimon_sad.wav`**, **`paimon_happy.wav`**: Crystal-clear voice files generated by Gemini's state-of-the-art TTS model.

### 🚀 Running the Demo Recorder

You can easily regenerate the demo video and audio on any platform.

#### **On Linux (Headless/Server with Xvfb)**:
```bash
# Start the virtual frame buffer and run the automated simulation
xvfb-run -s "-screen 0 320x320x24" python demo_recorder.py
```

#### **On Windows (Local Desktop)**:
```cmd
# Run directly - watch Paimon pop up on your screen and chat automatically!
python demo_recorder.py
```

## Project Structure

- `main.py` - App entry point and orchestration
- `config.py` - Configuration, constants, and personality settings
- `gui.py` - Tkinter window and mood image display
- `audio.py` - Text-to-speech generation and audio playback
- `chat.py` - Conversation loop, streaming responses, and mood handling
- `paimon_images/` - Mood image assets used by the GUI
- `ARCHITECTURE.md` - Developer guide for extending the app

## Requirements

- Python 3.10+
- `pillow`
- `google-genai`

Install dependencies with:

```bash
pip install pillow google-genai
```

## Setup

1. Place your mood images inside `paimon_images/`.
2. Required image names:
   - `happy.png`
   - `thinking.png`
   - `sad.png`
   - `angry.png`
3. Verify your `PROJECT_ID` in `config.py`.

## Run

```bash
python main.py
```

## Usage

- Type messages into the console.
- Paimon will respond with text, voice, and mood images.
- Type `exit` to end the chat.

## Notes

- The GUI runs on the main thread and receives updates from the chat thread safely.
- The application uses a modular design so new features can be added in separate files.
- For architecture details, see `ARCHITECTURE.md`.
